# 娄瑞嘉个人主页

这是一份可直接发布到 GitHub Pages 的纯静态个人简历，内容聚焦 LLM Infra、Agent Evaluation 与平台工程。

## 发布

1. 在 GitHub 新建一个公开仓库。若仓库名为 `heyMahalo.github.io`，主页地址会是 `https://heyMahalo.github.io/`；使用其他仓库名时，地址通常为 `https://heyMahalo.github.io/仓库名/`。
2. 将本目录全部内容（包括隐藏的 `.github` 与 `.nojekyll`）提交到仓库的 `main` 分支。
3. 在仓库 `Settings → Pages` 中将发布来源设为 `GitHub Actions`。
4. 等待仓库的 `Actions` 页面显示部署成功。

如果将本目录放在已有仓库的 `lou-ruijia-github-pages/` 子目录中，请把 Pages 工作流里的 artifact 路径改为 `./lou-ruijia-github-pages`；否则建议把本目录内容直接放在仓库根目录。

页面无需安装依赖，也不依赖构建工具。修改文案时编辑 `index.html`；修改样式时编辑 `styles.css`。

页面中的国防科技大学、东北林业大学校徽使用公开可访问的 SVG 资源；淘宝与华为图标使用 Simple Icons 的 SVG 资源。相关名称与标识的权利归各自机构/品牌所有，本页面仅用于个人履历中的教育与工作经历展示。
